Same cards on your phone and Mac

Sync keeps one collection on all your devices. It is stored in a private repository in your own GitHub account (free). Changes made on one device appear on the others within a few seconds of opening the app.

One-time setup
  1. On github.com click + → New repository. Name it opcg-data, choose Private, tick Add a README, and create it.
  2. Open github.com/settings/personal-access-tokens/new. Name: opcg-sync. Repository access: Only select repositories → opcg-data. Under Repository permissions set Contents to Read and write. Click Generate token and copy it.
  3. Paste below and tap Connect. On your other devices open this same app page and repeat step 3 with the same repository and token.

The token is kept only on the device where you paste it and can be revoked any time in GitHub. If the same card is edited on two devices at once, the most recent edit wins. Deleting a card on one device deletes it on the others.
Load Yuyu-tei prices

Yuyu-tei blocks automatic price updates from the website's server, but your own browser can open its pages. Save the set pages you need and load them here. Prices are kept on this device and used for those cards.

  1. Open each page below in a new tab (they are the sets in your collection).
  2. Press Cmd+S (Windows: Ctrl+S) and save it as Webpage, HTML only (or "Complete"). Keep the file names.
  3. Come back and choose the saved files. You can pick several at once.
